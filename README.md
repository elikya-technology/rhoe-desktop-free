# 🏗️ 8. Creating Native Windows Executables & Installers

To distribute Rhoe™ as a **native Windows package**, use **Launch4j** and **Inno Setup**.  
This process creates a **professional, standalone installer** for end-users. 💼✨


### 🛠️ Create an EXE with Launch4j
- Launch4j will wrap the **JAR** into a Windows executable **(.exe)**.
- Set the **“Bundled LibericaJRE path”** to a relative directory (e.g., `.\jre`) 📁  
  → This tells the EXE to use the Java Runtime packaged beside it.

### 📦 Build the Installer with Inno Setup
- Inno Setup creates a **single setup file** (📥 `Elikya Rhoe.exe`).
- The installer script must include:
  - the generated **EXE** ⚙️
  - a compatible **JRE folder** ☕📁
- The installer places both the EXE and the `jre` folder in the **same directory** on the user’s machine.

### 🎉 Final Result
You get a **single installer file** that deploys a **fully self-contained application**, capable of running **offline** and **without requiring the user to install Java**. 🚀💻
